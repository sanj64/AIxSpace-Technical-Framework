# Security policy

Do not include customer telemetry, credentials, private keys, export-controlled data, or
unredacted audit records in a public report. For this pre-release repository, report a
suspected vulnerability privately to the selling company’s designated Security/Privacy
Owner. A monitored disclosure address and safe-harbour policy must be established before
external distribution.

Supported versions and response targets are defined only by an executed order form/SLA.
Known exploitable critical vulnerabilities block release.
