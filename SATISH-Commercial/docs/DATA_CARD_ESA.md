# Dataset card — ESA Anomaly Dataset

- Source: ESA Anomaly Dataset, Zenodo record 12528696.
- License stated by the source: CC BY 3.0 IGO.
- Distribution policy: dataset files are not included in SATISH bundles.
- Acquisition: customer/evaluator uses the downloader with an approved file URL and
  expected SHA-256 value, then records the dataset ID/hash in the run manifest.
- Required attribution: identify ESA/source authors and DOI exactly as published.
- Required modification notice: state sorting, channel mapping, causal imputation,
  filtering, labels, and effective split boundaries.
- No endorsement: neither product material nor UI may imply ESA approval or endorsement.

Mission 1 and Mission 2 should be evaluated separately and together. Preserve source
subsystem mappings, event intervals, and rare nominal events. A release report must show
effective row/event counts and any exclusions. Counsel must approve the final attribution
and redistribution posture.
