# Paid-evaluation feedback protocol

For each operator session, collect comprehension of the detector/risk/policy explanation,
ability to identify its limits, perceived pressure to accept, false-trust indicators,
usefulness by UI layer, time to disposition, false-positive/false-negative observations,
known rare nominal events, failed prerequisites, and requested configuration changes.
Separate usability opinion from measured detector performance. Obtain privacy/contractual
authority, minimize operator identifiers, and predefine retention/deletion. Product, Model
Risk, and Safety owners review the report before any v1.0 gate can pass.
