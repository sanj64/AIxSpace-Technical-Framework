# Validation Status

Historical validation reports based on `segments_clean` and `dataset_clean` have been archived and are no longer active evidence.

The active repository does not claim operational validation, flight readiness, certification, or universal model accuracy. The current verified state is:

- ESA archive integrity and schema checks are implemented.
- Historical CSV training inputs are rejected by active training paths.
- Leakage-safe chronological split and train-only scaling helpers are implemented and tested.
- Full model retraining is blocked until complete ESA telemetry values from Zenodo record 12528696 are available locally.

## Metrics

No active model metrics are published in this checkout. Accuracy, precision, recall, F1, ROC-AUC, PR-AUC, confusion matrices, threshold curves, calibration analysis, and feature importance must be regenerated by the reproducible ESA rebuild workflow before publication.

## Acceptance Rule

Any future validation report must include the ESA source hash evidence, exact split boundaries, scaler fit partition, code commit, model configuration, output hashes, and remaining limitations.
