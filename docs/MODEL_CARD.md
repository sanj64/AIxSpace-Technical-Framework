No active trained anomaly model is published by this checkout.

Historical model artifacts have been archived because they were not reproducibly regenerated from the verified ESA dataset in the corrected pipeline.

## Intended Future Model Evidence

A future active model card must include:

- ESA source file hashes.
- Mission selection and preprocessing configuration.
- Train, validation, and test split boundaries.
- Scaler fit partition.
- Model initialization seed and hyperparameters.
- Metrics with uncertainty where applicable.
- Calibration analysis.
- Known limitations and failure modes.
